# Welcome to LKE Inc

Internal engineering organization and repositories for LKE Inc.

### Engineering Guidelines
- All development follows our branch and pull request process.
- Direct commits to `main` are blocked across all repositories.
- At least one full-time employee review is required before merging.
- See [`CONTRIBUTING.md`](https://github.com/LKE-Execs/.github/blob/main/CONTRIBUTING.md) for full branch naming and commit conventions.
